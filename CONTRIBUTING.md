# Contributing

Contributions are welcome for routing accuracy, portability, safety, documentation, and reproducible evaluations.

## Development

1. Fork and clone the repository.
2. Create a focused branch.
3. Keep changes within one clear capability or safety improvement.
4. Do not commit generated catalogs, backups, quarantined source, credentials, or machine paths.
5. Run all validation commands from README.
6. Explain behavior changes, safety impact, and test evidence in the pull request.

New preferred routes need a synthetic case and evidence that the capability is installed and invocable. New external candidates belong in research records, not in the runtime skill.

By contributing, you agree that your contribution is licensed under Apache-2.0.
