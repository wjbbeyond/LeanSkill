# Security policy

## Supported versions

Security fixes are provided for the latest Beta release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or open a private security advisory for this repository. Do not publish secrets, exploit details, private paths, or affected user data in a public issue.

Include the affected version, operating system, reproduction steps, impact, and any proposed mitigation. Reports will be acknowledged as soon as practical.

## Scope

Security issues include unsafe global configuration mutation, rollback failure, path traversal, accidental secret or local-inventory publication, candidate execution outside quarantine, and permission escalation beyond documented behavior.
